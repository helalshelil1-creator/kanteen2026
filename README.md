# 🛒 كانتِين | Kanteen

> **شبيك لبيك... كانتين بين ايدك**

منصة تجارة إلكترونية مصرية لتوصيل البقالة والمستلزمات اليومية لباب بيتك في دقائق.

🔗 **الموقع:** https://kanteen.vercel.app

## ✨ الميزات

- 🎨 تصميم عصري بـ Glassmorphism + Silver Shine
- 🛍️ 52 منتج + 10 أقسام
- 🛒 سلة + مفضلة + Checkout 6 خطوات
- 🎁 4 كوبونات خصم + نظام نقاط ولاء
- 🚚 تتبع طلبات مباشر + Live Map
- 🤖 مساعد ذكي عربي
- 🎤 بحث صوتي (ar-EG)
- 👨‍🍳 وصفات ذكية
- 🏪 12 سوبر ماركت + خريطة
- 📊 لوحة إدارة + Charts
- 🌙 Dark/Light Mode
- 📱 PWA - يعمل Offline
